# 설아의 한자 공부

React 19 + TypeScript + Vite + Tailwind CSS로 만든 서버 없는 한국어 한자 학습 PWA입니다.

## 실행

Node.js 22 이상에서:

```sh
npm ci --cache /tmp/npm-cache
npm run dev
```

`npm run build`는 타입 검사와 프로덕션 빌드를 실행합니다. `npm run preview -- --port 4173`으로 빌드를 확인할 수 있습니다. PWA 설치와 오프라인 캐시는 HTTPS 또는 localhost에서 프로덕션 빌드를 한 번 열어 서비스 워커가 설치된 뒤 작동합니다. 첫 방문에는 인터넷이 필요합니다.

## 구현

- 홈 진도, 마지막 한자 이어보기, 150자 목록, 8급/7급 선택과 완료/미학습 필터
- 한자 학습, 완료/해제, 이전/다음 이동
- 로컬 SVG 획순 애니메이션 (제공되는 자형), Pointer Events 기반 벡터 필기, 따라/혼자 쓰기, 공통 펜·지우개·모두 지우기
- 완료한 글자만 최대 10개 중복 없이 무작위 출제하는 두 가지 자가 채점 테스트
- 정답 공개 후 채점, 오답 복습, 결과 및 날짜/유형/문제별 정오 기록
- IndexedDB 저장, 저장 실패 안내, 테스트 이탈 확인, 반응형 화면, PWA 정적 자료 캐싱

필기는 SVG 벡터로 구현해 화면 회전/고해상도에서도 좌표와 선명도를 유지합니다. 자동 필기 인식이나 자동 채점은 하지 않습니다. 필기 자체는 연습용이며 페이지 이동 시 초기화됩니다. 학습 기록은 브라우저 데이터 삭제 시 사라집니다.

## 교육 자료의 한계 — 배포 전 검수 필요

8급 50자와 7급 추가 100자(준7급 포함), 누적 150자를 제공합니다. 공개 학습 목록 두 곳에서 7급 추가 100자의 집합이 일치하는 것을 확인했습니다. 기존 8급에서 누락된 王을 추가하고 少는 7급으로 정정했습니다. 기존 학습 기록은 글자 ID가 같으므로 그대로 유지됩니다. 공식 사이트는 환경의 도메인 제한으로 접속되지 않아 최신 공식 배정표와의 재확인은 대기 중입니다. 출처, 대조 범위, 한계는 [CATALOG-SOURCES.md](CATALOG-SOURCES.md)에 기록했습니다.

획수는 `hanzi-writer-data`의 실제 획 수에서 추출했습니다. 이 자료는 중국 자형 기준이므로 한국어문회 기준과 차이가 있을 수 있습니다. `敎`는 데이터셋에 없어 획수/획순을 미제공으로 표시하며 다른 자형으로 임의 대체하지 않았습니다. 150자 모두 뜻을 떠올리는 기억 그림을 제공합니다. 숫자는 점의 개수로 표시합니다. 그림은 암기를 돕는 시각 자료이며 한자의 유래나 역사적 자형을 설명하지 않습니다. 각 데이터에 급수, 순서, 출처, 검증 상태 및 향후 자료 필드를 분리했습니다.

Hanzi Writer 코드는 MIT, 획 데이터는 Make Me a Hanzi/Arphic 기반 Arphic Public License입니다. 원본 라이선스는 `public/STROKE-LICENSE.txt`에 포함되어 있습니다. 데이터 갱신 시 `node scripts/data.mjs`를 실행하세요.

## 검증

```sh
npm test
npm run build
# 별도 터미널에서 npm run preview -- --port 4173 실행 후
node scripts/browser-check.cjs
```

브라우저 검증은 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 해당 경로를 설치된 Chromium으로 조정하세요. 150자 고유성/획 데이터 일치, 출제 범위/중복/개수, 점수 계산을 단위 테스트합니다. 브라우저 검증은 독립된 두 필기판/밑글씨 보존/화면 크기 변경, 학습 영속성, 두 테스트 유형, 결과 영속성, 모바일 가로 넘침, 오프라인 재접속/획 자료 로드를 확인합니다.

후속 작업: 공식 한자 자료 대조, 한국 표준 획순 확인, 실제 Galaxy Tab·iPad·Android 펜 및 설치 동작 확인.

## GitHub Pages 배포

사이트 기본 경로는 `/hanja/`입니다. 로컬 미리보기도 `/hanja/`로 접속하세요.
`main`에 푸시하면 GitHub Actions가 테스트와 빌드 후 생성된 정적 파일을 `gh-pages` 브랜치에 게시합니다.
저장소 Settings → Pages에서 Source를 **Deploy from a branch**, Branch를 **gh-pages / (root)**로 설정하세요.
예정 주소: https://hgh-dev.github.io/hanja/

## 자동 업데이트

앱이 열려 있으면 새 버전을 15초마다 확인하며, 다시 전면으로 돌아오거나 인터넷 연결이 복구될 때도 확인합니다. 새 버전이 준비되면 ‘업데이트하기’ 버튼을 표시하고, 사용자가 누르면 즉시 적용하고 새로고침합니다. 새로고침 시 진행 중인 필기나 아직 제출하지 않은 테스트는 초기화될 수 있습니다. 서비스 워커는 앱을 처음 연 뒤 설치되므로 최초 방문에는 기존 버전이 없습니다.

로컬 검증: 프로덕션 미리보기를 실행하고 `node scripts/update-check.cjs`를 실행하면 업데이트 설치 후 업데이트 버튼 표시와 클릭 후 새로고침을 확인합니다.

## 폴드·태블릿 학습 화면

한자와 기억 그림은 한 영역에, 획순 애니메이션과 필기는 다른 영역에 배치했습니다. Galaxy Fold 안쪽·바깥쪽 화면과 Galaxy Tab 가로·세로 비율에서 학습 화면이 스크롤 없이 표시되도록 조정했습니다. `node scripts/tablet-check.cjs`로 대표 화면 크기의 스크롤과 영역 잘림을 확인할 수 있습니다. 전체 150자 목록은 탐색을 위해 스크롤합니다.

스마트폰 세로 학습 화면에서 한자와 기억 그림은 좌우 같은 너비를, 태블릿에서는 위아래 같은 높이를 차지합니다. 연습 영역은 위쪽 획순 보기, 아래쪽 쓰기 연습으로 배치합니다. `node scripts/tablet-check.cjs`가 대표 화면 크기에서 이 비율과 상하 배치를 검사합니다.

기본 한자, 목록/테스트 글자와 따라쓰기 밑글씨는 획순 데이터의 SVG 경로를 공통으로 사용합니다. 데이터가 없는 敎 또는 로딩 실패 시에는 글꼴로 대체합니다. 앱 안에서는 contextmenu 이벤트와 모바일 텍스트 길게 누르기 메뉴를 차단합니다.

학습 화면에는 따라쓰기와 혼자쓰기 필기판을 동시에 표시하며, 펜과 지우개는 공통 도구로 선택하며 모두 지우기는 양쪽 필기선을 함께 지웁니다. 그림과 획순/필기판은 제목과 조작 버튼을 제외한 실제 여유 공간에 맞춰 크기를 계산합니다.
